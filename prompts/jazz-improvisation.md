# Jazz Piano Improvisation Guide

## Jazz Harmony Basics

### Common Chord Progressions

**ii-V-I (most common):**
```
Dm7(62,65,69,72) → G7(67,71,74,77) → Cmaj7(60,64,67,71)
```

**I-vi-ii-V (turnaround):**
```
Cmaj7(60,64,67,71) → Am7(57,60,64,67) → Dm7(62,65,69,72) → G7(67,71,74,77)
```

**iii-vi-ii-V (extended turnaround):**
```
Em7(64,67,71,74) → Am7(57,60,64,67) → Dm7(62,65,69,72) → G7(67,71,74,77)
```

### Chord Voicings

**Rootless voicings (left hand):**
- **Cmaj7**: E4(64)-G4(67)-B4(71)-D5(74)
- **Dm7**: F4(65)-A4(69)-C5(72)-E5(76)
- **G7**: F4(65)-A4(69)-B4(71)-D5(74)

**Shell voicings (minimal):**
- **Cmaj7**: E4(64)-B4(71)
- **Dm7**: F4(65)-C5(72)
- **G7**: F4(65)-B4(71)

## Scales for Improvisation

### Major Scale Modes
- **Ionian (Major)**: C-D-E-F-G-A-B (over Cmaj7)
- **Dorian**: D-E-F-G-A-B-C (over Dm7)
- **Mixolydian**: G-A-B-C-D-E-F (over G7)

### Pentatonic Scales
- **Major Pentatonic**: C-D-E-G-A (over Cmaj7)
- **Minor Pentatonic**: A-C-D-E-G (over Am7)

### Bebop Scales
- **Bebop Dominant**: G-A-B-C-D-E-F-F# (over G7)
- **Bebop Major**: C-D-E-F-G-G#-A-B (over Cmaj7)

## Improvisation Techniques

### Approach Patterns

**Chromatic approach:**
```
Target: C4(60)
Approach: B3(59) → C4(60) or C#4(61) → C4(60)
```

**Diatonic approach:**
```
Target: C4(60)
Approach: D4(62) → C4(60) or B3(59) → C4(60)
```

**Enclosure (surround target):**
```
Target: C4(60)
Enclosure: D4(62) → B3(59) → C4(60)
```

### Bebop Lines

**Descending bebop line over ii-V-I:**
```
Dm7: F4(65) → E4(64) → D4(62) → C4(60)
G7:  B4(71) → A4(69) → G4(67) → F4(65)
Cmaj7: E4(64) → D4(62) → C4(60) → B3(59)
```

**Ascending bebop line:**
```
Dm7: D4(62) → E4(64) → F4(65) → G4(67)
G7:  A4(69) → B4(71) → C5(72) → D5(74)
Cmaj7: E5(76) → D5(74) → C5(72) → B4(71)
```

### Blues Scale Usage

**C Blues Scale:**
```
C(60) → Eb(63) → F(65) → F#(66) → G(67) → Bb(70) → C(72)
```

**Application:**
- Over C7: Use C blues scale
- Over F7: Use F blues scale (F-Ab-Bb-B-C-Eb)
- Over G7: Use G blues scale (G-Bb-C-Db-D-F)

## Rhythmic Ideas

### Swing Feel
Eighth notes played as triplet pattern:
```
Written: 1 & 2 & 3 & 4 &
Played:  1  a  2  a  3  a  4  a
(Long-short: 0.67 + 0.33 of beat)
```

### Syncopation Patterns

**Anticipation:**
```
Beat:   1    &    2    &    3    &    4    &
Note:   .    .    .    X    .    .    .    X
(Notes anticipate beats 2 and 4)
```

**Delayed resolution:**
```
Beat:   1    &    2    &    3    &    4    &
Note:   X    .    X    .    X    .    .    X
(Resolution delayed from beat 4 to "and" of 4)
```

## Solo Construction

### Structure
1. **Start simple**: 2-3 notes, clear rhythm
2. **Develop**: Add complexity gradually
3. **Climax**: Highest note, fastest rhythm, loudest velocity
4. **Resolve**: Return to simple, stable notes

### Dynamics
```
Opening: 60-70 (piano)
Building: 70-85 (mezzo-forte)
Climax: 85-100 (forte)
Resolution: 60-75 (piano to mezzo-piano)
```

### Range Usage
- **Low register (48-60)**: Intimate, warm
- **Middle register (60-72)**: Normal, conversational
- **High register (72-84)**: Bright, intense
- **Extreme high (84-96)**: Climactic, rare

## Common Jazz Patterns

### Turnaround Patterns

**I-vi-ii-V in C:**
```
Cmaj7: C4(60) → E4(64) → G4(67)
Am7:  A3(57) → C4(60) → E4(64)
Dm7:  D4(62) → F4(65) → A4(69)
G7:   G4(67) → B4(71) → D5(74)
```

### ii-V Patterns

**Basic ii-V in C:**
```
Dm7: F4(65) → E4(64) → D4(62)
G7:  F4(65) → E4(64) → D4(62) → C4(60)
```

**Chromatic ii-V:**
```
Dm7: F4(65) → E4(64) → Eb4(63) → D4(62)
G7:  F4(65) → E4(64) → Eb4(63) → D4(62) → C4(60)
```

## Practice Patterns

### Pattern 1: Scale runs
```
C major ascending: C4(60) → D4(62) → E4(64) → F4(65) → G4(67) → A4(69) → B4(71) → C5(72)
```

### Pattern 2: Arpeggios
```
Cmaj7: C4(60) → E4(64) → G4(67) → B4(71) → C5(72)
```

### Pattern 3: Enclosures
```
Target C4: D4(62) → B3(59) → C4(60)
Target E4: F4(65) → D4(62) → E4(64)
Target G4: A4(69) → F4(65) → G4(67)
```
